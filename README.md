# Partikel Semesta

Game incremental berbasis web bertema "pondasi inti alam semesta", dibuat untuk **Lomba Programming ISCOMFEST 2026**. Terinspirasi dari *Antimatter Dimensions* dan *Legends of Idleon*.

- Website: [isi link]
- Video demo: [isi link]

## Cara Bermain

1. Mulai dengan 10 poin. Beli upgrade pertama seharga 10 poin, lalu poin bertambah otomatis.
2. Upgrade 1 memproduksi poin, Upgrade 2 memproduksi Upgrade 1, dan seterusnya.
3. Harga upgrade naik secara eksponensial.
4. Gunakan **Rebirth** untuk mengulang progres dan mendapat bonus penghasilan persentase.

## Cara Menjalankan

1. Unduh repository ini (**Code → Download ZIP**), lalu ekstrak.
2. Buka `index.html` di browser.

Tidak perlu instalasi, backend, maupun database.

## Teknologi

HTML, CSS, dan JavaScript (vanilla).
